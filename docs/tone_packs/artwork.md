# Tone3000 Tone Pack Artwork Guidelines & SPICE Schematic Design

This document is the Single Source of Truth (SSOT) for designing, generating, and verifying **Allomorph Tone Pack** cover artwork (`tone3000/assets/allomorph_*.svg`, `tone3000/assets/allomorph_*.jpg`, and `tone3000/packs/*/artwork.jpg`). All artwork is programmatically generated by [`scripts/generate_tone3000_artwork.py`](../../scripts/generate_tone3000_artwork.py).

---

## 1. Tone3000 Platform Guidelines & Automated Scanner Compliance

Tone3000 enforces strict automated and moderator-reviewed rules on all uploaded Tone Pack cover images ([Tone3000 Tone Sharing Guidelines — Tone Pack Images](https://www.tone3000.com/guides/tone-sharing-guidelines#tone-pack-images-important)). Images that violate these rules are **automatically scanned and removed**.

### 1.1 Prohibited Elements (Never Include)
1. **No Promotional Graphics, Logos, or Typography Banners:**
   - Do **not** include brand headers (`"ALLOMORPH"`), subtitle banners (`"ANALOG PICKUP DIGITAL TWINS"`), platform badges (`"FOR NAM & ANAGRAM"`), scale-length pills (`"34\" SCALE"`), or voicing count footers (`"35 VOICINGS"`).
   - Tone3000's scanner flags promotional text overlays and marketing badges as prohibited *"Graphics or logos"*.
2. **No Stock Photos or AI-Generated Art:**
   - Do **not** use stock photos of instruments, amplifiers, or AI-generated illustrations.
3. **No SPICE Netlist Directives or Code Blocks:**
   - Allomorph is a first-principles Modified Nodal Analysis (MNA) and state-space simulation engine—it does not use SPICE netlist text files. Do **not** add `.subckt`, `.param`, `.tran`, or `.ac` text blocks to the canvas.

### 1.2 The Tone3000 "Circuit Models" Rule
Because Allomorph models electroacoustic pickups, passive RLC networks, and active preamps in code, our packs fall under Tone3000's **Circuit Models** category:

> **Circuit Models:** *"Use a diagram of your circuit as the main image, such as a LiveSPICE or SPICE schematic, or a circuit diagram for models built in code. You may overlay the diagram on a stock photo of the gear on a black background. Make the circuit the most dominant part of the image, so it’s clear the pack is a circuit model."*

## 2. Allomorph Visual Architecture: Pickup-Sculpted SPICE Schematics

To satisfy Tone3000's Circuit Models requirement while making each bass archetype immediately recognizable at thumbnail size, every Allomorph cover image renders a **SPICE circuit schematic sculpted directly in the physical shape and layout of the instrument's pickups**, overlaid on a muted dark pickup silhouette and full-bleed vertical bass strings.

### 2.1 Four-Layer Composition Stack (Back to Front)

Each image is authored on a `1200 × 1200` coordinate canvas (`viewBox="0 0 1200 1200"`) and exported to a `1024 × 1024` production JPEG:

1. **Layer 1 — Dark EDA Schematic Canvas & Grid:**
   - Deep dark background (`#07090e` to `#030407`) with a `24 px` minor grid (`#spiceGridMinor`) and `120 px` major grid (`#spiceGridMajor`) subtly tinted in the pack's accent color, plus a soft radial glow (`#centerGlow`) behind the pickup region.
2. **Layer 2 — Full-Bleed Wound Bass Strings (`y = 0` to `y = 1200`):**
   - Vertical roundwound bass strings (`make_strings_underlay`) must extend **all the way from the top edge (`y1="0"`) to the bottom edge (`y2="1200"`)** of the image.
   - String gauges taper progressively from low Bass (`B`/`E`) to Treble (`G`), rendered with a dark metallic core and a dashed winding texture (`stroke-dasharray="4 6"`).
3. **Layer 3 — Muted Ghost Pickup Silhouette Underlay:**
   - Dark, low-contrast pickup casings (`fill="#070a10" fill-opacity="0.90"`), subtle mounting screw ears, dashed coil-winding perimeters, and dark recessed pole pieces or magnetic blades positioned at the exact string `x` coordinates.
4. **Layer 4 — Dominant SPICE Circuit Schematic Sculpted Inside the Pickups:**
   - High-contrast schematic wires (`stroke={accent}`), glowing white/accent IEEE circuit symbols, white-centered solder nodes (`spice_node`), earth ground references (`spice_gnd`), and a right-hand output port (`V_OUT`) form the dominant visual subject.
   - All inter-pickup wiring (series hum-canceling links, parallel volume/tone buses, active op-amp summing stages) is routed tightly between the pickups so the overall silhouette matches the physical pickup arrangement on a bass body.

## 4. Geometric Invariants & Layout Rules

When modifying existing artwork or creating artwork for a new tone pack, strictly enforce the following geometric invariants:

### 4.1 Standardized String Spacing (`strings_4` and `strings_5`)
Strings must be spaced wide enough that multi-part pickups (especially Split-P halves) fit comfortably over their string pairs without overlapping across the canvas centerline (`x = 600.0`):

- **4-String Packs (`strings_4`):**
  $$x_{\text{strings}, 4} = [300.0,\ 500.0,\ 700.0,\ 900.0] \quad (\Delta x = 200.0\text{ px})$$
  - Bass pair (`E`, `A`) is at `x = 300.0, 500.0` $\implies$ pair midpoint is **`cx = 400.0`**.
  - Treble pair (`D`, `G`) is at `x = 700.0, 900.0` $\implies$ pair midpoint is **`cx = 800.0`**.
- **5-String Packs (`strings_5`):**
  $$x_{\text{strings}, 5} = [280.0,\ 440.0,\ 600.0,\ 760.0,\ 920.0] \quad (\Delta x = 160.0\text{ px})$$
  - Centered symmetrically on the D-string at **`cx = 600.0`**.

### 4.2 Split-Coil Pickup Centering & Non-Overlap Rule
For any Split-P pickup (`make_pbass_spice_bobbin` and `make_pbass_ghost_shell`):
1. **Exact String-Pair Centering:**
   - The E/A bobbin **must** be centered at `cx = 400.0` with `x_strings = (300.0, 500.0)`.
   - The D/G bobbin **must** be centered at `cx = 800.0` with `x_strings = (700.0, 900.0)`.
2. **Bobbin Width Bound (`w = 396.0`):**
   - With `200 px` string spacing, each Split-P half has `w = 396.0` (`< 400.0`), so the E/A bobbin spans `x = 202..598` and the D/G bobbin spans `x = 602..998`. They meet cleanly at the `x = 600.0` centerline without overlapping into the adjacent string pair's space.
3. **Internal SPICE Loop Symmetry:**
   - Inside `make_pbass_spice_bobbin`, the parallel tank rectangle must be symmetric around `cx` (`xL = cx - w/2 + 30.0`, `xR = cx + w/2 - 30.0`), with the AC source at `cx - 100.0` (aligned with the left string of the pair), the inductor centered at `cx`, and `R_dc` centered at `cx + 100.0` (aligned with the right string of the pair).

### 4.3 Full-Width Pickups (Jazz, Soapbar, StingRay)
- Full-width single-coils (`make_jbass_spice_bobbin`), dual-coil soapbars (`make_soapbar_spice_bobbin`), and Music Man humbuckers (`make_stingray_ghost_shell`) are centered horizontally at **`cx = 600.0`** with width **`w = 820.0` to `840.0`**, spanning `x = 180..1020` so all 4 or 5 strings pass cleanly through the interior of the pickup housing with comfortable margin inside the coil perimeter.

### 4.4 Zero Wire/Label Collision Rule
1. **Opaque Label Pills:** Every component label (`_label_pill`) renders inside a high-contrast dark rounded rectangle (`fill="#06090f" opacity="0.92"`) so background strings or ghost pole pieces never obscure component text.
2. **Explicit Label Placement (`label_pos` / `align`):**
   - Components on the **top branch** of a parallel loop must set `label_pos="top"` (placed outside/above the loop).
   - Components on the **bottom branch** of a parallel loop must set `label_pos="bottom"` (placed outside/below the loop).
   - Components on the **center branch** must stagger their `x` coordinates or place labels in open interior space so they never intersect top/bottom rails or vertical cross-bars.

## 5. How to Add or Regenerate Tone Pack Artwork

### 5.1 Modifying or Adding a Pack in `scripts/generate_tone3000_artwork.py`
1. **Register the Mapping:**
   Add or update the model key in `MODEL_PACK_MAP` in [`scripts/generate_tone3000_artwork.py`](../../scripts/generate_tone3000_artwork.py):
   ```python
   MODEL_PACK_MAP = {
       "precision": ("allomorph_standard_precision_bass", "34in_standard_p"),
       ...
   }
   ```
2. **Define the Layout in `generate_pack_svg(model_key)`:**
   - Choose a unique hex `accent` color.
   - Set `num_strings` (`4` or `5`).
   - Compose the pickup-sculpted SPICE schematic inside `"content": _svg_content(lambda accent: ...)` using the modular builders (`make_pbass_spice_bobbin`, `make_jbass_spice_bobbin`, `make_soapbar_spice_bobbin`, `spice_resistor_h/v`, `spice_inductor_h`, `spice_capacitor_h/v`, `spice_zener_pair_h`, `spice_opamp`, `spice_gnd`, `spice_node`, `spice_port`).
3. **Run the Generator Script:**
   ```bash
   uv run python scripts/generate_tone3000_artwork.py
   ```
   This script automatically:
   - Validates every SVG with `xml.etree.ElementTree.fromstring()` to guarantee well-formed XML.
   - Writes `tone3000/assets/allomorph_<name>.svg`.
   - Renders a `1024 × 1024` production JPEG (`tone3000/assets/allomorph_<name>.jpg`) via macOS `qlmanage` + `sips`.
   - Syncs the rendered JPEG directly to `tone3000/packs/<pack_id>/artwork.jpg`.

### 5.2 Verification Checklist
After regenerating artwork, always run:
1. **Visual Inspection:** View the generated `.jpg` files in `tone3000/assets/` to verify string centering, pickup alignment, and zero label overlaps.
2. **Automated Compliance & Guardrail Tests:**
   ```bash
   uv run pytest tests/allomorph/tone3000/test_tone3000.py tests/allomorph/test_guardrails.py
   ```
   `test_tone3000_artwork_files_exist` in [`tests/allomorph/tone3000/test_tone3000.py`](../../tests/allomorph/tone3000/test_tone3000.py) programmatically verifies that all 7 SVGs and JPGs exist, contain the SPICE schematic markers (`spiceGridMajor`, `V_OUT`), and contain **zero** banned promotional banner strings (`ANALOG PICKUP DIGITAL TWINS`, `FOR NAM & ANAGRAM`).
